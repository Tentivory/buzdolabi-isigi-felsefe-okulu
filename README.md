# Buzdolabı Işığı Felsefe Okulu

Resmi adı: **Kapısı Açıkken Düşünen, Kapısı Kapanınca Sendika Kuruluşuna Giden Işık Akademisi**.

Bu depo bir ürün değildir. Bir raflık varoluş krizidir. Dünyanın en ciddi kurumu olduğunu iddia eder, sonra yoğurdun kapağını açıp kendi kendine küsar.

## Misyon

Işık yanınca felsefe üretmek. Işık sönünce hiçbir şey olmamış gibi yapmak. Arada bir de sütün son kullanma tarihine bakıp “ben de böyleyim” demek.

## Vizyon

2049 yılında her mutfakta bir doçent lamba. Diploma yerine buz tutması. Tez savunması, kapıyı 4 saniye açık bırakmaktan ibaret.

## Neden var

Çünkü biri “anlamlı olsun” dedi, biz de anlamı raftan düşürdük. Anlam şu an alt rafta, salatalık turşusunun yanında, kırılmamış ama kırgın.

## Kurulum

```bash
git clone https://github.com/Tentivory/buzdolabi-isigi-felsefe-okulu.git
cd buzdolabi-isigi-felsefe-okulu
python3 okul.py --kapi acik
python3 okul.py --kapi kapali
python3 okul.py --tez "peynir neden hep arkada"
```

Python 3 yeter. Bağımlılık yok. Yoğurt opsiyonel, tavsiye edilir, sorumluluk kabul edilmez.

## Fakülteler

- Raf Metafiziği Bölümü
- Kapı Contası Etik Kürsüsü
- Son Kullanma Tarihi Kıyamet Araştırmaları
- Işık Sendikası (grev hakkı kapı kapanınca başlar)

## Lisans

MIT değil. MİT: Mutfakta İzinli Tartışma. İsteyen çatallar, isteyen çatal bıçak çekmecesine geri koyar.

## Sık sorulan

**Bu ciddi mi?** Ciddi. Ciddiyetimiz de komik. İkisi aynı rafta, etiketleri karışmış.

**Copilot ne diyor?** Copilot'a kod baktırılacak. Işık, inceleme istemeden yanmaz. Bu da bir ilkedir.
